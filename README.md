# jwst_Viewer

The code provides interface for jwst pipeline v2.0.0

How to run the code
1) download it directly or by
   git clone https://github.com/slavaklimenko/jwst_Viewer

2) edit path to your uncalib files in "init.dat" file

3) create a conda environment and install the following packages:
python                    3.11.0
asdf                      2.15.0
astropy                   5.3
jwst                      1.11.0 
pyqt5                     5.15.9 
pyqt5-qt5                 5.15.2
pyqt5-sip                 12.12.1
pyqtgraph                 0.13.3
python                    3.11.0 
scipy                     1.9.3 
stdatamodels              1.7.0
stsci-image               2.3.5
stsci-imagestats          1.6.3
stsci-stimage             0.2.6

You can simply use:

$ pip install -r /path/to/requirements.txt


4) run main.py file
