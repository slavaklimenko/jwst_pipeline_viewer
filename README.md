# jwst_Viewer
How to run the code
1) edit path to your uncalib files in "init.dat" file
2) create conda env and install following packages:
asdf                      2.15.0                   pypi_0    pypi
astropy                   5.3                      pypi_0    pypi
jwst                      1.11.0                   pypi_0    pypi
pyqt5                     5.15.9                   pypi_0    pypi
pyqt5-qt5                 5.15.2                   pypi_0    pypi
pyqt5-sip                 12.12.1                  pypi_0    pypi
pyqtgraph                 0.13.3                   pypi_0    pypi
python                    3.11.0          he550d4f_1_cpython    conda-forge
scipy                     1.9.3                    pypi_0    pypi
stdatamodels              1.7.0                    pypi_0    pypi
stsci-image               2.3.5                    pypi_0    pypi
stsci-imagestats          1.6.3                    pypi_0    pypi
stsci-stimage             0.2.6                    pypi_0    pypi
3) run main.py file
